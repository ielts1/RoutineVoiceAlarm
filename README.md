# Routine Voice Alarm — Final Project

A native Android daily/weekly routine alarm app.

## Included
- Separate routine for every day of the week.
- Select one or multiple days for each alarm.
- Multiple alarms per day.
- Enable/disable alarms.
- Edit and delete alarms.
- Exact next-occurrence scheduling.
- Alarm re-scheduling after reboot.
- Alarm re-scheduling after exact-alarm access is restored.
- High-priority notification with full-screen alarm UI.
- Ringtone playback.
- Bengali/English Text-to-Speech using the text entered by the user.
- Stop and Snooze.
- Local storage only; no account or internet required.
- Permission/setup screen for exact alarms and notifications.

## Important Android behavior
Android may apply manufacturer-specific battery restrictions. If an OEM puts the app into an aggressive restricted state, alarm delivery can be affected. The app cannot override those system restrictions.

## Build
Open/import this folder as an Android Gradle project. The project targets Android API 35 and uses Java 17 source/target compatibility.
